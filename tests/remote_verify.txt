另外确认：

- `.git/config` 不含令牌（remote URL 为干净的 `https://github.com/vip-svip/Syfuse.git`）
- 未使用 `git remote set-url` 拼令牌，未使用 `credential.helper store`
- 推送使用一次性注入：`git -c http.extraheader="Authorization: Basic <b64(x-access-token:TOKEN)>" push`

> **实测更正**：提示词 1.3 建议的 `Authorization: Bearer $GH_TOKEN` 对
> **git smart HTTP 无效**，实测返回 `remote: invalid credentials`。
> 必须使用 Basic 且用户名为 `x-access-token`。REST API 用 Bearer 正常。
> 这一点应反馈到提示词。
