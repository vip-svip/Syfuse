# apk/ —— 内置软件（sidecar APK）产物占位

本目录在**源码树中为空**。`package.sh` 会把构建好的 APK 复制到这里，
再打进模块 ZIP 的 `apk/syfuse.apk`，由 `customize.sh` / `action.sh` 第 1 项安装。

为什么要有这个目录：提示词 3.1 的产品形态是
**模块内置 APK**（模块给系统级能力，App 给界面与配置）。
所以 APK 是模块的**内置组件**，不是独立分发的应用。

**当前状态：未注入。** M1 只交付模块骨架；
APK 随包在 App 侧功能可用后注入（M14 打包校验时必需）。
